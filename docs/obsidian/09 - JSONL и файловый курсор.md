# JSONL и файловый курсор

## Что такое JSONL

JSONL - текстовый формат, в котором каждая строка содержит отдельный JSON-объект.

Упрощённый пример:

```json
{"file":"chunk_0001.cf32","samples_count":1000}
{"file":"chunk_0002.cf32","samples_count":1000}
```

Одна строка metadata соответствует одному IQ-файлу.

## Файловый курсор

После:

```matlab
fid = fopen(path, "r");
```

открытый файл хранит текущую позицию чтения.

Вызов:

```matlab
line = fgets(fid);
```

читает следующую строку и перемещает курсор вперёд.

```mermaid
flowchart LR
    Before["Курсор перед строкой 1"] -->|"fgets"| After1["Курсор перед строкой 2"]
    After1 -->|"fgets"| After2["Курсор перед строкой 3"]
    After2 -->|"fgets"| EOF["EOF"]
```

## Recorded-режим

Для последовательного воспроизведения не нужно выполнять `fseek`.

Алгоритм:

```text
прочитать следующую строку
если строки нет и достигнут EOF:
    завершить воспроизведение
иначе:
    декодировать JSON
```

## Realtime-режим

Для режима свежих данных используется другая политика:

```text
перейти к концу уже накопленных metadata
ждать новую полную строку
декодировать JSON
```

Проверка `endsWith(json_line, newline)` нужна, чтобы не принять частично записанную строку.

## EOF

Функция `feof(fid)` показывает, был ли конец файла достигнут предыдущей операцией.

Это важно: открытие пустого файла само по себе ещё не выставляет EOF. Обычно сначала выполняется попытка чтения, затем проверяется результат и `feof`.
