## Общая схема

```mermaid
flowchart TD
    Config["Configurator"] --> Source["Конкретный источник данных"]
    Source --> IQ["IQ-компоненты"]
    Source --> Meta["Метаданные"]
    IQ --> Math["Математический блок"]
    Meta --> Math
    Math --> Output["Блок вывода"]
```
