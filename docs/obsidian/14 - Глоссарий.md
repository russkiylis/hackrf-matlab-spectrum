# Глоссарий

## Абстрактный класс

Класс, объект которого нельзя создать напрямую. Он описывает общую основу для наследников.

Пример: `FileDataSource`.

## Абстрактный метод

Декларация обязательного метода без реализации. Конкретный наследник обязан предоставить реализацию.

Пример:

```matlab
[iq_complex, metadata] = nextData(obj);
```

## Контракт

Набор операций и смыслов, которые один блок обещает внешнему коду.

Пример: любой источник данных должен уметь вернуть следующий чанк через `nextData()`.

## Чанк

Одна порция IQ-данных вместе с относящимися к ней метаданными.

## Metadata

Описание чанка:

```text
имя файла
количество samples
частота дискретизации
центральная частота
полоса
время
```

## JSONL

Формат, в котором каждая строка является отдельным JSON-объектом.

## IQ

Комплексные отсчёты сигнала:

```text
I - in-phase component
Q - quadrature component
```

## EOF

End of file. Состояние, означающее, что чтение достигло конца файла.

Для recorded-источника EOF является нормальным завершением записи.

## Handle-класс

MATLAB-класс со ссылочной семантикой. Наследуется от `handle`.

Изменения объекта видны всем переменным, которые ссылаются на тот же объект.

## Protected-метод

Метод, доступный самому классу и его наследникам, но скрытый от внешнего кода.

Пример: `FileDataSource.readIQ()`.

## Транспорт

Способ доставки данных:

```text
файлы
сеть
```

Транспорт не должен определять математическую обработку.

## Политика

Решение о поведении блока в конкретном сценарии.

Пример:

```text
RecordedFileDataSource читает все metadata по порядку.
RealtimeFileDataSource ждёт свежие metadata.
```
