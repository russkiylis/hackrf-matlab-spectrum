## Ближайшие задачи

### 1. Исправить realtime-очистку

Сейчас используется:

```matlab
delete(fullfile(obj.folder_path, "*.cf32"));
```

Нужно удалить риск гонки. Источник должен очищать только конкретные обработанные или явно пропущенные чанки.

Связанная заметка: [[10 - Жизненный цикл файлов]].

### 2. Нормализовать char и string

В некоторых сообщениях ошибок используется:

```matlab
"Текст" + file_path
```

Если `file_path` является `char`, вместо ожидаемой ошибки может возникнуть ошибка конкатенации.

Нужно выбрать единый подход:

```text
приведение пути к string
или форматирование сообщения
```

### 3. Гарантировать fclose через onCleanup

Если чтение IQ завершится ошибкой после `fopen`, текущий код может не дойти до `fclose`.

См. [onCleanup](https://www.mathworks.com/help/matlab/ref/oncleanup.html).

### 4. Подключить источники к pipeline

Сейчас [[27 - Source - pipeline|pipeline.m]] всё ещё использует старый `RealtimeWasserfall`.

Следующая архитектурная цель:

```mermaid
flowchart LR
    Config["Configurator"] --> Source["DataSource"]
    Source --> Math["Математический блок"]
    Math --> Output["Блок вывода"]
```

### 5. Отделить математический блок
