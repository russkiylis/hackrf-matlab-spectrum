# Сценарии использования

## Зачем нужны сценарии

Архитектуру полезно проверять не только диаграммами, но и простыми историями использования.

Если сценарий можно описать коротко, а детали транспорта остаются внутри источника, границы выбраны удачно.

## Сценарий 1. Просмотр сохранённой записи

```mermaid
sequenceDiagram
    participant App as Pipeline
    participant Config as Configurator
    participant Source as RecordedFileDataSource
    participant JSONL as metadata.jsonl
    participant IQ as chunk.cf32

    App->>Config: getDataSource()
    Config-->>App: RecordedFileDataSource
    App->>Source: nextData()
    Source->>JSONL: fgets()
    JSONL-->>Source: metadata следующего чанка
    Source->>IQ: fread()
    IQ-->>Source: float32 I/Q
    Source-->>App: complex IQ + metadata
```

После последней строки источник возвращает EOF-состояние.

Подробнее: [[07 - RecordedFileDataSource]].

## Сценарий 2. Запуск MATLAB до GNU Radio

```mermaid
sequenceDiagram
    participant App as Pipeline
    participant Source as RealtimeFileDataSource
    participant GNU as GNU Radio

    App->>Source: создать источник
    Source->>Source: waitForFile(metadata.jsonl, 30)
    Note over Source: источник ожидает запуск GNU Radio
    GNU->>Source: создать metadata.jsonl
    Source->>Source: открыть metadata.jsonl
    Source-->>App: источник готов
```

Подробнее: [[08 - RealtimeFileDataSource]].

## Сценарий 3. Получение свежего чанка

```mermaid
sequenceDiagram
    participant App as Pipeline
    participant Source as RealtimeFileDataSource
    participant GNU as GNU Radio

    App->>Source: nextData()
    Source->>Source: перейти в EOF metadata.jsonl
    GNU->>GNU: завершить chunk.tmp
    GNU->>GNU: rename chunk.tmp -> chunk.cf32
    GNU->>Source: дописать полную строку JSONL
    Source->>Source: jsondecode()
    Source->>Source: readIQ(metadata)
    Source-->>App: complex IQ + metadata
```

## Сценарий 4. Будущая замена транспорта

```mermaid
flowchart TD
    Config["Configurator"] --> Choice{"config.data_source.type"}
    Choice -->|"file_recorded"| Recorded["RecordedFileDataSource"]
    Choice -->|"file_realtime"| Realtime["RealtimeFileDataSource"]
    Choice -->|"network"| Network["Будущий SocketDataSource"]
    Recorded --> Contract["nextData()"]
    Realtime --> Contract
    Network --> Contract
    Contract --> Math["Математический блок"]
```

Математический блок не меняется.

Подробнее: [[12 - Переход к сети]].

## Минимальный внешний интерфейс

Внешнему коду достаточно:

```matlab
configurator = Configurator(config);
source = configurator.getDataSource();
[iq_complex, metadata] = source.nextData();
```

Здесь нет чтения JSONL, `fopen`, `fgets`, `fread` и `fseek`. Эти детали скрыты внутри файловой ветки.
