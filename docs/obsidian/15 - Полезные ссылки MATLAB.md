# Полезные ссылки MATLAB

Несмотря на название файла, здесь собраны также ссылки по Obsidian и JSONL: они помогают работать с этой базой знаний и понимать формат metadata.

## Классы и наследование

- [Subclass Syntax](https://www.mathworks.com/help/matlab/matlab_oop/subclass-syntax.html) - синтаксис наследования.
- [Design Subclass Constructors](https://www.mathworks.com/help/matlab/matlab_oop/subclass-constructors.html) - вызов конструктора родителя из наследника.
- [Class Constructor Methods](https://www.mathworks.com/help/matlab/matlab_oop/class-constructor-methods.html) - устройство конструкторов.
- [Class Members Access](https://www.mathworks.com/help/matlab/matlab_oop/selective-access-to-class-methods.html) - `public`, `protected`, `private` и абстрактные методы.
- [Class Attributes](https://www.mathworks.com/help/matlab/matlab_oop/class-attributes.html) - атрибуты классов, включая `Abstract`.

## Файлы

- [fopen](https://www.mathworks.com/help/matlab/ref/fopen.html) - открыть файл.
- [fclose](https://www.mathworks.com/help/matlab/ref/fclose.html) - закрыть файл.
- [fgets](https://www.mathworks.com/help/matlab/ref/fgets.html) - прочитать строку с переводом строки.
- [feof](https://www.mathworks.com/help/matlab/ref/feof.html) - проверить достижение EOF.
- [fseek](https://www.mathworks.com/help/matlab/ref/fseek.html) - переместить файловый курсор.
- [ftell](https://www.mathworks.com/help/matlab/ref/ftell.html) - получить позицию файлового курсора.
- [fread](https://www.mathworks.com/help/matlab/ref/fread.html) - прочитать бинарные данные.
- [fullfile](https://www.mathworks.com/help/matlab/ref/fullfile.html) - собрать путь из частей.
- [delete](https://www.mathworks.com/help/matlab/ref/delete.html) - удалить файл или объект.

## Безопасное освобождение ресурсов

- [onCleanup](https://www.mathworks.com/help/matlab/ref/oncleanup.html) - выполнить очистку при выходе из функции.
- [Clean Up When Functions Complete](https://www.mathworks.com/help/matlab/matlab_prog/cleaning-up-when-the-function-completes.html) - пояснение паттерна очистки.

## Obsidian и диаграммы

- [Internal links - Obsidian Help](https://help.obsidian.md/links) - форматы внутренних ссылок, включая wikilinks.
- [Basic formatting syntax - Obsidian Help](https://help.obsidian.md/syntax) - Markdown-синтаксис заметок.
- [Mermaid documentation](https://mermaid.js.org/intro/) - документация по диаграммам в блоках `mermaid`.

## JSONL

- [JSON Lines](https://jsonlines.org/) - описание построчного JSON-формата.
